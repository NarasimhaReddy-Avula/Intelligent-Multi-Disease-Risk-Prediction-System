### Week 4 Meeting
**Date:** Feb 9-10, 2026 | **Attendees:** Student, Dr. R. Selvi

**Discussion Points:**
- Combined all 4 unified datasets (202,723 samples)
- Missing value analysis and imputation strategy
- Masked vs Sentinel approach comparison

**Completed Tasks:**
- [x] Combined datasets (src/data/combine_datasets.py)
- [x] Analyzed missing values (60.46% structural missingness)
- [x] Created masked version (48 features)
- [x] Created sentinel version (24 features, -999)
- [x] Documented strategy in TECHNICAL_DOCS.md

**Key Decisions:**

1. **No Standard Imputation:** Our data has structural missingness (features never collected), not random missingness. KNN/MICE would create false medical data.

2. **Two Imputation Versions Created:**
   - **Masked (Primary):** feature_value + feature_mask columns
     - Explicit signal: mask=0 means "ignore this value"
     - Best for FT-Transformer (attention learns from masks)
   - **Sentinel (Comparison):** -999 for missing values
     - Clearly outside scaled range (-999 vs typical -3 to +3)
     - Works with tree models (XGBoost, RF)

3. **Why -999 not -1:** After StandardScaler, real values fall in [-3, +3]. Sentinel -1 would overlap with scaled low values. -999 is clearly distinguishable.

4. **Target Handling:** Each sample has one disease label only. Other targets are NaN. Use masked loss during training.

**Files Created:**
- datasets/combined_unified.csv (original, 29 cols)
- datasets/combined_unified_masked.csv (51 cols)
- datasets/combined_unified_sentinel.csv (29 cols)
- src/data/impute_missing_values_masked.py
- src/data/impute_missing_values_sentinel.py
- src/data/analyze_missing_values.py
- notebooks/eda/figures/week4/*.png (visualizations)
